# 論理回路まなびゲーム

中学生が、ミニゲームを遊ぶうちに「1と0」「論理ゲート」「組み合わせ回路」「順序回路」を理解できるようにするゲームです。
1は水が流れている、0は水がない、に例えます。

## 仕様

- 仕様書は Claude Docs にあります（ユーザー体験・操作性の2つに分けています）。
  - 仕様書：https://claude.ai/artifact/VDcrhkTJNjbqCRtpBfMGcE
  - 操作性仕様書：https://claude.ai/artifact/DFN5ifVBnQG4MT9XAdqHM4

## 進み具合

- [x] 回路の評価と正解判定（`src/logic.js`）
- [x] 組み合わせ回路編 ステージ1〜8の定義（`src/stages.js`）
- [x] 画面（組み合わせ編）：仕掛けの配置・移動・削除、水路（ドラッグ、または2回タップ）、蛇口、準備完了（実行）、元に戻す、ヒント、進み具合の保存
- [x] 実行のアニメーション：蛇口から水を順にたどり、水路→仕掛け→出口の順に結果を見せる。蛇口を触ったときも同じように水が進む
- [x] チュートリアル（ステージ1・2）、ステージごとの目標の表示、蛇口・花・おやじ・仕掛けのイラスト
- [x] 庭のパン（1本指で空いたところをドラッグ）・ピンチ拡大・ホイール拡大、空いたところの2回タップで庭全体
- [ ] 画面の残り：長押しメニュー、効果音と振動、設定画面、ふりがな
- [ ] 順序回路編

## 開発

依存パッケージはありません（Node.js 18 以上）。

```sh
npm test
```

画面を見る（ビルドは不要）:

```sh
python serve.py
# ブラウザで http://localhost:8000/ を開く
```

`index.html` を直接（ダブルクリックで）開いても動きません。`python -m http.server` は、Windows では `.js` を正しく返さないことがあるので、`serve.py` を使ってください。
