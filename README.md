# 論理回路まなびゲーム

中学生が、ミニゲームを遊ぶうちに「1と0」「論理ゲート」「組み合わせ回路」「順序回路」を理解できるようにするゲームです。
1は水が流れている、0は水がない、に例えます。

## 開発

依存パッケージはありません（Node.js 18 以上）。

```sh
npm test
```

ステージを作ったり変えたりしたら、パズルとして成り立っているかを確かめる（`npm test` にも入っている）:

```sh
node tools/audit.js
```

ステージの決まり：仕掛け箱の仕掛けは、どれを1つ抜いても、それまでに出てきた別の仕掛けに替えても解けないこと。
時間が1回だけだと、カタブツ（AND）とイエスマン（OR）は同じ水を両方の入口に入れると水路と同じになるので、
AND・OR・XOR を使うステージは2回以上にする。仕掛けが3つ以上のステージは、4回（朝・昼・夕方・夜）でないと作れないことが多い。

画面を見る（ビルドは不要）:

```sh
python serve.py
# ブラウザで http://localhost:8000/ を開く
```

`index.html` を直接（ダブルクリックで）開いても動きません。`python -m http.server` は、Windows では `.js` を正しく返さないことがあるので、`serve.py` を使ってください。
